# LEARNINGS_LOG.md

**Companion file to BUILDER_CODEX.md** — this is where rules get *tested*, not where they get invented.

---

## Why this file exists

BUILDER_CODEX.md says what the rules are.
This file is where you prove they're true (or find out they're wrong) by writing down what actually happened, every time you fix something real.

One rule for this whole file:

> **If a capture takes more than 60 seconds to write, you're doing too much. Stop and just write the 3 lines.**

This is not a research database. It's not a framework. It's a notebook.
The only thing that earns a place here is something that *actually happened* in a real project (Puff Stick, PIKA, Pippa, Matarani, TÉYA, whatever) — not a theory, not something you read on Twitter.

---

## How to add an entry

Right after you fix something — not later, not "I'll batch it on Friday" — add one block at the top of the **Log** section below:

```
### [YYYY-MM-DD] [project] short title

- Problem:
- Cause:
- Fix that worked:
```

That's it. Three lines. Thai or English, whichever is faster to type in the moment.

If you want to add a 4th line because something surprised you, fine — but don't make it a habit. The moment this turns into a 10-field schema, you'll stop filling it in, and an empty system is worse than no system.

---

## The only "upgrade" rule

Don't touch BUILDER_CODEX.md every time you write an entry.

Once a month (or whenever you think of it — no need to be strict), skim the Log below and ask one question:

> **"Did the same root cause show up 3+ times?"**

If yes → that's a real rule now. Move it into BUILDER_CODEX.md as a proper rule, and delete or strike through the old entries here so the log doesn't get cluttered with solved problems.

If no → leave everything alone and keep building. Most entries will never get promoted, and that's fine. They did their job just by existing in case you need to check "wait, didn't I hit this before?"

No promotion ladder, no Pattern/Principle/Framework pipeline. Just: **3+ times → graduate to BUILDER_CODEX.md. Otherwise → stays here as a record.**
